# Programa Regional Transversal de IA (PRT-IA)

Propuesta web institucional para presentar un mecanismo regional de cooperación tecnológica: conectividad adecuada al contexto, acceso comunitario a IA, auditoría algorítmica basada en riesgo, capacidades tecnológicas locales y cofinanciación transparente.

## Ejecutar localmente

El sitio es estático y no necesita instalar dependencias. Desde esta carpeta, inicia un servidor estático con Python:

```powershell
python -m http.server 8000
```

Abre `http://localhost:8000`. También puedes abrir `index.html` directamente en el navegador.

## Archivos

- `index.html`: entrada para servir el sitio estático y publicarlo con GitHub Pages.
- `outputs/PRT-IA.html`: copia de trabajo original del proyecto.

El contenido financiero, la gobernanza, los plazos y los mecanismos descritos son propuestas sujetas a negociación. No representan aprobación institucional. El panel de indicadores no contiene resultados inventados.

## Publicación

Para GitHub Pages, selecciona la rama `main` y la carpeta raíz (`/`) en la configuración de Pages del repositorio.
